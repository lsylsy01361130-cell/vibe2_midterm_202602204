# 서연커피 주문·관리 웹앱

서연커피의 음료와 디저트를 둘러보고 주문할 수 있는 단일 페이지 앱웹입니다. 주문을 접수하면 메뉴 재고와 레시피에 따른 부재료 재고가 차감되며, 매장 관리 화면에서 주문 제조 현황과 재고를 확인할 수 있습니다.

## 링크

- GitHub 저장소: [https://github.com/lsylsy01361130-cell/vibe2_midterm_202602204](https://github.com/lsylsy01361130-cell/vibe2_midterm_202602204)
- GitHub Pages: [https://lsylsy01361130-cell.github.io/vibe2_midterm_202602204/](https://lsylsy01361130-cell.github.io/vibe2_midterm_202602204/)

> **배포 상태:** 2026년 10월 22일 확인 기준, GitHub Pages 주소에서 404 응답이 확인되어 아직 공개 배포를 확인할 수 없습니다. 저장소의 **Settings → Pages**에서 배포 소스와 브랜치를 설정한 후 위 주소에서 확인해 주세요.

## 앱 소개

- 음료 10종과 디저트 4종의 메뉴, 가격, 설명, 칼로리, 재고를 확인합니다.
- 음료에는 샷 추가(+500원)와 시럽 추가(+0원) 옵션이 제공됩니다.
- 메뉴를 장바구니에 담고 수량을 조정하거나 삭제한 뒤 주문할 수 있습니다.
- 주문 후 주문번호와 제조 진행 상태를 확인할 수 있습니다.
- 매장 관리 화면에서 주문을 확인하고 제조 준비 시작 및 제조 완료 처리를 할 수 있습니다.
- 메뉴 재고와 음료 레시피의 부재료 재고를 확인하며, 주문 접수 시 재고가 자동 차감됩니다. 필요한 재고가 부족하면 주문이 차단됩니다.
- 크림·세이지·청록 계열 색상과 커피·디저트 이모지 패턴을 적용했습니다.

## 사용법

### 고객 주문

1. `index.html`을 브라우저에서 열거나 GitHub Pages 배포가 완료된 경우 배포 링크에 접속합니다.
2. `메뉴 주문` 화면에서 음료 또는 디저트를 살펴봅니다.
3. 음료는 원하는 경우 샷 추가 또는 시럽 추가를 선택하고 `바구니에 담기`를 누릅니다. 디저트에는 추가 옵션이 없습니다.
4. 장바구니에서 수량을 조정하거나 항목을 삭제하고 합계를 확인합니다.
5. `주문하기`를 누르면 주문이 접수되고 메뉴 및 부재료 재고가 차감됩니다.
6. 메뉴 위의 `내 주문 제조 현황`에서 주문번호와 진행 상태를 확인합니다. 제조 완료 주문은 `확인` 버튼으로 목록에서 닫을 수 있습니다.

### 매장 관리

1. 화면 상단의 `매장 관리` 탭을 선택합니다.
2. `주문 현황`에서 최신 주문을 확인합니다.
3. 주문의 `제조 준비 시작`을 누른 뒤 제조가 끝나면 `제조 완료 처리`를 누릅니다.
4. `메뉴별 재고`와 `부재료 재고`에서 잔량과 부족 경고를 확인합니다.
5. `메뉴 주문` 탭으로 돌아가면 고객 화면에도 주문 진행 상태가 반영됩니다.

## 실행 및 데이터 안내

- 별도의 설치나 빌드 없이 `index.html`을 최신 브라우저에서 열어 실행할 수 있습니다.
- 앱 데이터는 현재 브라우저의 `localStorage`에 저장됩니다. 같은 브라우저에서 열면 주문과 재고가 유지됩니다.
- 이 앱은 데모·프로토타입이며, 관리자 인증, 결제, 서버 저장, 서로 다른 기기 간 데이터 공유는 제공하지 않습니다.
- 레시피와 부재료 초기 재고는 데모 기준값입니다. 실제 운영에 사용하기 전에 매장 기준에 맞게 조정해야 합니다.
